## Сообщение об уязвимости

Не создавайте публичный issue для проблем безопасности.

Напишите на почту: **metusallo@gmail.com**

В письме укажите:

- версию Windows;
- описание проблемы и шаги воспроизведения;
- возможные последствия.

Ответ — в течение 7 дней. После исправления информация публикуется в описании релиза.

## Область ответственности

PSEyes — локальное настольное приложение. Оно не передаёт данные в сеть,
но использует внешние компоненты:

- **ffmpeg** (`C:\ffmpeg\bin\ffmpeg.exe`) — устанавливается отдельно; его уязвимости
  вне зоны ответственности проекта, обновляйте его самостоятельно;
- **драйвер камеры PS Eye** (Universal PS3 Eye Driver / Code Laboratories);
- **PowerShell-скрипты** в `tools/driver_fix/` — изменяют драйверы USB-устройства,
  требуют прав администратора (UAC). Просмотрите их перед запуском;
- приложение может запросить права администратора для перезапуска USB-устройства
  камеры (`pnputil /restart-device`) при устранении ошибки драйвера (код 10).

## Зависимости

Уязвимости в зависимостях Python (PyQt6, opencv-python, numpy) отслеживайте через
`python -m pip list --outdated` и обновляйте пакеты.
